# edf-project-rands-ui

[Back to Main README](../../../README.md)

## Description
Contains UI components for managing and visualizing edf project rands. This includes pages for building and editing edf project rands, viewing the JSON representation, and tables for listing available edf project rands.

## Features

- edf-project-rand-builder-page.component (module)
- edf-project-rand-json-page.component (module)
- edf-project-rand-table.component (module)
- edf-project-rands-consumption.component (module)

## Running unit tests

Run `nx test edf-project-rands-ui` to execute the unit tests via [Vitest](https://vitest.dev/).
