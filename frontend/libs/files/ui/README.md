# files-ui

[Back to Main README](../../../README.md)

## Description
Contains UI components for file interaction. This includes a table for listing files, and buttons for uploading and downloading files.

## Features

- file-table.component (module)
- upload-button.component (module)
- download-button.component (module)

## Running unit tests

Run `nx test files-ui` to execute the unit tests via [Vitest](https://vitest.dev/).
