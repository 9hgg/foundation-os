# utils

[Back to Main README](../../README.md)

## Description
A comprehensive collection of shared utility functions, Angular directives, pipes, and services used across the Spoken application. This library serves as a foundational layer, providing essential functionality for:
-   **Caching**: HTTP request caching and storage management.
-   **UI Enhancements**: Directives for autofocus, drag-and-drop, resize, and scroll tracking.
-   **Data Formatting**: Pipes for date formatting, duration, and sanitization.
-   **Helpers**: Utilities for math, strings, colors, and JWT handling.
