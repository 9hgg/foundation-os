# users-state

[Back to Main README](../../../README.md)

## Description
Manages the state of user data within the application. It includes the repository for fetching and storing user information and services for handling user sessions.

## Features

- users.repository (module)
- user-sessions.service (module)

Run `nx test users-state` to execute the unit tests via [Vitest](https://vitest.dev/).
